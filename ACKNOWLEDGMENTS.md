## English

### CodexBar

Parts of Kabul's usage features were based on ideas from
[CodexBar](https://github.com/steipete/CodexBar) by Peter Steinberger (MIT License):

- showing every provider's limits, reset windows and spend in the menu bar;
- which provider sources expose usage data;
- an optional data source: when CodexBar is installed, Kabul can read the JSON output of its CLI
  (`codexbar usage --format json`). You can turn this off in Settings › General.

Kabul's code is its own. It does not include CodexBar source code. Thank you, Peter, for building and
sharing CodexBar.

### Conductor

Kabul is an independent, open-source project. The workflow of
[Conductor](https://conductor.build), an app for running coding agents in parallel workspaces, served as
a reference for parts of Kabul's experience.

Kabul does not use any source code from Conductor or from the company that makes it. Kabul was written
from scratch. Kabul is not affiliated with, endorsed by or sponsored by Conductor or its makers.
"Conductor" is a trademark of its respective owner.

### Other projects

Kabul is built on many open-source projects. Each one keeps its own license; see the `Cargo.lock` and
`package-lock.json` files for the complete list.

## Português

### CodexBar

Partes dos recursos de uso do Kabul foram baseadas em ideias do
[CodexBar](https://github.com/steipete/CodexBar), de Peter Steinberger (licença MIT):

- mostrar os limites, as janelas de renovação e o gasto de cada provedor na barra de menus;
- quais fontes de cada provedor expõem dados de uso;
- uma fonte de dados opcional: quando o CodexBar está instalado, o Kabul pode ler a saída JSON do CLI
  dele (`codexbar usage --format json`). Dá para desligar em Configurações › Geral.

O código do Kabul é próprio. Ele não inclui código-fonte do CodexBar. Obrigado, Peter, por criar e
compartilhar o CodexBar.

### Conductor

O Kabul é um projeto independente e de código aberto. O fluxo de trabalho do
[Conductor](https://conductor.build), um app para rodar agentes de código em workspaces paralelos, serviu
de referência para partes da experiência do Kabul.

O Kabul não usa nenhuma linha de código do Conductor nem da empresa que o desenvolve. O Kabul foi escrito
do zero. O Kabul não tem vínculo com o Conductor nem com quem o desenvolve, e não é endossado nem
patrocinado por eles. "Conductor" é marca de seu respectivo dono.

### Outros projetos

O Kabul é construído sobre muitos projetos de código aberto. Cada um mantém sua própria licença; veja os
arquivos `Cargo.lock` e `package-lock.json` para a lista completa.

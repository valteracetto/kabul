# Keyboard shortcuts

On Windows, `⌘` will be `Ctrl`. The same list is in **Settings › Shortcuts** (`⌘⌥/`), with search.

### General

| Shortcut | Action |
|---|---|
| `⌘K` | Command palette (workspaces, actions, settings, chats) |
| `⌘,` | Settings |
| `⌘⌥/` | Keyboard shortcuts |
| `⌘⌥T` | Cycle theme (dark, light, system) |
| `⌘⌥F` | Send feedback |
| `⌘⌥I` | Developer tools |
| `⌃1 … ⌃9` | Switch machine |
| `⌘Q` | Quit (asks if agents are running) |

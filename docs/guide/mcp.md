# MCP

The MCP button in the composer lists the servers the agent sees (user and project scope), their live status in the session and their tools. Turn a server off for this session or for the repository, and add a new server (command and arguments). For Claude, sessions with servers turned off start with only the enabled ones (`--mcp-config` and `--strict-mcp-config`).

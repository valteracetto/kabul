# Themes

**Settings › Appearance**: light, dark or system theme (`⌘⌥T` cycles), app zoom (`⌘+`, `⌘−`, `⌘0`), low-contrast dark mode, color-blind friendly colors (deuteranopia, protanopia, tritanopia), monospace font, Markdown style (default or Tufte), code ligatures, colored diff counts in the sidebar and terminal font and size. The interface uses Geist and Geist Mono (SIL Open Font License).

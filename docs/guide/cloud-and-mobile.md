# Cloud and mobile

- **Provider cloud.** From the `+` tab menu choose **Provider cloud (Claude)** to start `claude --cloud` for the workspace. The tab shows the session status, opens it on claude.ai and can bring it back to the Mac (**teleport**).
- **Mirror to phone.** **Mirror on phone/claude.ai** (workspace `···` menu) keeps the session running on the Mac and visible in the Claude app.
- **Other machines.** Add machines running `kabuld` in **Settings › Machines** (for example `mac-studio.tailnet.ts.net:7777`) and switch with the machine picker or `⌃1` … `⌃9`.
![Machine picker](/screens/maquinas-pop.png)

- **Sessions panel.** **Panel** in the sidebar lists every tmux session with the detected agent, cloud sessions and imported sessions.

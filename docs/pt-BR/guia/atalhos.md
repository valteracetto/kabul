# Atalhos de teclado

No Windows, `⌘` será `Ctrl`. A mesma lista está em **Configurações › Atalhos** (`⌘⌥/`), com busca.

### Geral

| Atalho | Ação |
|---|---|
| `⌘K` | Paleta de comandos (workspaces, ações, configurações, conversas) |
| `⌘,` | Configurações |
| `⌘⌥/` | Atalhos de teclado |
| `⌘⌥T` | Alternar tema (escuro, claro, sistema) |
| `⌘⌥F` | Enviar feedback |
| `⌘⌥I` | Ferramentas de depuração |
| `⌃1 … ⌃9` | Trocar de máquina |
| `⌘Q` | Sair (pergunta se há agentes rodando) |

### Ver

| Atalho | Ação |
|---|---|
| `⌘B` | Mostrar/ocultar barra lateral |
| `⌘⌥B` | Mostrar/ocultar painel direito |
| `⌘J` | Mostrar/ocultar terminal |
| `⌘.` | Modo zen |
| `⌘+ / ⌘− / ⌘0` | Zoom do app (50% a 300%) |

### Navegação

| Atalho | Ação |
|---|---|
| `⌘[ / ⌘]` | Voltar / avançar |
| `⌘⇧H` | Início |
| `⌘1 … ⌘9` | Ir para o workspace N |
| `⌘⌥↑ / ⌘⌥↓` | Workspace anterior / próximo |
| `⌘⌥L` | Próximo workspace que pede atenção |
| `⌘P` | Abrir arquivo |
| `⌘⇧F` | Buscar nos arquivos |

### Workspace

| Atalho | Ação |
|---|---|
| `⌘N` | Novo workspace |
| `⌘⇧N` | Criar a partir de PR, branch ou issue |
| `⌘⌥A` | Adicionar projeto |
| `⌘⇧A` | Arquivar workspace |
| `⌘⇧C` | Copiar link do workspace |
| `⌘O / ⌘⇧O` | Abrir no app padrão / escolher o app |
| `R / P` | No menu de contexto: lido/não lido, fixar |

### Abas

| Atalho | Ação |
|---|---|
| `⌘T` | Nova conversa |
| `⌘W` | Fechar aba |
| `⌘⇧T` | Reabrir a aba fechada (ou novo terminal) |
| `⌃Tab / ⌃⇧Tab` | Próxima / anterior aba (também ⌘⇧] / ⌘⇧[) |
| `⌘D` | Dividir com a próxima aba / desfazer a divisão |
| `⌘⇧B` | Aba Browser (navegador do workspace, compartilhado com os agentes) |

### Chat

| Atalho | Ação |
|---|---|
| `↵ / ⇧↵` | Enviar / nova linha (ou ⌘↵, nas configurações) |
| `⌘L` | Focar o campo de mensagem |
| `⌘U` | Anexar arquivo |
| `⌘/` | Seletor de modelo |
| `⌘⇧/` | Alternar esforço |
| `⌘⇧E` | Modo rápido |
| `⌃⌘1 … 9` | Modelo favorito N |
| `⇧⇥` | Plan mode |
| `⌘⇧↵` | Aprovar o plano |
| `↵ / ⌘↵ / ⌫` | Aprovar / sempre permitir / negar (campo vazio) |
| `⌘⇧⌫ / Esc` | Parar o agente |
| `⌃O` | Recolher/mostrar passos do agente |
| `⌘⌥↵` | Fork da conversa para nova aba |
| `⌘⌥C` | Copiar transcript |
| `⌘F / ⌘G / ⌘⇧G` | Buscar no chat / próximo / anterior |
| `⌃⇧D` | Ditado |
| `1–9 / 0 / ← →` | Perguntas do agente: opção / outra / navegar |

### Git

| Atalho | Ação |
|---|---|
| `⌘⇧P` | Criar PR |
| `⌘⇧Y` | Commit e push (pelo agente) |
| `⌘⇧L` | Pull |
| `⌘⇧M` | Merge do PR |
| `⌘⇧X` | Corrigir erros dos checks |
| `⌘⇧G` | Abrir PR (GitHub, Linear ou Graphite) |
| `⌘⇧R` | Revisar as mudanças |

### Revisão de código

| Atalho | Ação |
|---|---|
| `↑ / ↓` | Arquivo anterior / próximo no diff |
| `⌘⌥K / ⌘⌥J` | Comentário anterior / próximo |
| `⌃V` | Marcar arquivo como visto |

### Terminal

| Atalho | Ação |
|---|---|
| `⌘F` | Buscar no terminal (com o foco nele) |
| `⌘K` | Limpar o terminal |
| `⌘R` | Rodar o run script |
| `⌘⇧B` | Abrir o último localhost do terminal na aba Browser |

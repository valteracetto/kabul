# Temas

**Configurações › Aparência**: tema claro, escuro ou do sistema (`⌘⌥T` alterna), zoom do app (`⌘+`, `⌘−`, `⌘0`), escuro de baixo contraste, cores para daltonismo (deuteranopia, protanopia, tritanopia), fonte monoespaçada, estilo do Markdown (padrão ou Tufte), ligaduras no código, contagem de diff colorida na barra lateral e fonte e tamanho do terminal. A interface usa Geist e Geist Mono (SIL Open Font License).

# MCP

O botão de MCP no composer lista os servidores que o agente vê (escopo do usuário e do projeto), o status deles na sessão e as ferramentas. Desligue um servidor nesta sessão ou no repositório e adicione um servidor novo (comando e argumentos). No Claude, sessões com servidores desligados começam só com os ligados (`--mcp-config` e `--strict-mcp-config`).

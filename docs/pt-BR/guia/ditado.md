# Ditado

`⌃⇧D` (ou o botão do microfone) grava e transcreve offline com o `whisper.cpp`. Instale `ffmpeg` e `whisper-cpp` pelo Homebrew e baixe um modelo; o Kabul acha nas pastas de cache de costume. O texto entra onde está o cursor.

No Windows, instale o `ffmpeg` (`winget install Gyan.FFmpeg`) e ponha o `whisper-cli.exe` no `PATH` (ou defina `KABUL_BIN_WHISPER_CLI`). No celular, o ditado usa o microfone pelo navegador e precisa de HTTPS (veja [Nuvem e celular](./nuvem-e-celular.md)).
